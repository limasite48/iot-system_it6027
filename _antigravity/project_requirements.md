Course: IT6027 - Cybersecurity Policy and Governance
Project Topic: System for detecting insecure IoT devices within a network. The system must include the following components:
- IoT device fingerprinting (cameras, smart plugs, etc.) via banner/mDNS/UPnP (mandatory)
- Firmware/CVE matching and checking for publicly known default passwords against a predefined list (mandatory)
- VLAN-based scoping, alerts, and a device-type dashboard (optional; counts as a bonus)
